# Настройка управляемого сервера для TG-Server-Admin-Bot

Инструкция по подготовке целевого Linux-узла (Ubuntu, Debian,
CentOS, Rocky Linux, AlmaLinux) для безопасного подключения и
управления ботом.

---

## Автоматическая настройка в 1 клик (рекомендуемый способ)

Для быстрой автоматической настройки выполните следующую команду на
подключаемом сервере от имени `root` или `sudo`:

```bash
wget -O setup_node.sh \
  'https://raw.githubusercontent.com/EvgenyElizarenko/'\
  'TG-Server-Admin-Bot/refs/heads/main/script'"'"'s/setup_node.sh' && \
  chmod +x setup_node.sh && \
  sudo ./setup_node.sh
```

### Что сделает скрипт

1. Проверит и установит необходимые системные утилиты (`curl`,
   `iproute2`, `vnstat`, `sudo`, `openssh-server`).
2. Создаст сервисного пользователя `botadmin`.
3. Добавит `botadmin` в группу `docker` (если Docker установлен на
   сервере).
4. Запросит ввод вашего персонального SSH-ключа (полученного в
   Telegram-боте по команде `/key`) и запишет его в
   `~/.ssh/authorized_keys` для `botadmin`.
5. Разместит системные скрипты управления в `/usr/local/sbin/`:
   - `update.sh` — скрипт автоматического обновления пакетов;
   - `root.sh` — временная активация Root-доступа по таймеру на 2
     минуты;
   - `unroot.sh` — принудительное отключение Root-доступа.
6. Сконфигурирует изолированные правила `sudoers` в
   `/etc/sudoers.d/botadmin` с проверкой синтаксиса через `visudo`.
7. Выведет сводку параметров (IP, активный SSH-порт, имя пользователя)
   для ввода в мастере добавления сервера в боте.
