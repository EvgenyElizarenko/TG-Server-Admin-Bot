## Кратко

Асинхронный Telegram-бот для централизованного мониторинга,
диагностики и безопасного администрирования Linux-серверов и Docker-
контейнеров. Он предназначен для операторов и администраторов,
которые хотят быстро получать состояние узлов, выполнять безопасные
операции по SSH и контролировать запуск административных задач без
лишних привилегий.

## Стек

- Язык: Python 3.10+
- Фреймворк: Aiogram 3
- Сетевой SSH: AsyncSSH
- Дополнительно: python-dotenv для конфигурации из .env

## Основные возможности

- Генерация персонального публичного SSH-ключа (команда /key) для
  авторизации на целевых серверах.
- Добавление и управление списком серверов через диалог в Telegram
  (TOFU-проверка отпечатка хоста).
- Фоновый мониторинг состояния узлов и Docker-контейнеров.
- Выполнение предопределённых административных команд с минимально
  необходимыми привилегиями через отдельного системного пользователя.
- Утилиты для временного включения root-доступа на 2 минуты и
  принудительного его отключения.
- Централизованное хранение метаданных: servers.json, users.json,
  known_hosts, audit.log.
- Запуск как systemd-служба (tg-server-bot.service) под
  непривилегированным пользователем.

## Короткая инструкция по запуску

Рекомендуется ознакомиться с подробными инструкциями в разделе
instruction. Быстрая автоматическая установка выполняется на хосте,
где будет работать бот:

```bash
wget -O install_bot.sh https://raw.githubusercontent.com/EvgenyElizarenko/TG-Server-Admin-Bot/refs/heads/main/script's/install_bot.sh && chmod +x install_bot.sh && sudo ./install_bot.sh
```

Настройка управляемого узла выполняется на целевом сервере:

```bash
wget -O setup_node.sh https://raw.githubusercontent.com/EvgenyElizarenko/TG-Server-Admin-Bot/refs/heads/main/script's/setup_node.sh && chmod +x setup_node.sh && sudo ./setup_node.sh
```

## Быстрые шаги после установки

1. Откройте бота в Telegram и отправьте `/start`.
2. Получите персональный публичный ключ: `/key`.
3. На целевом сервере добавьте публичный ключ в
   `/home/<botuser>/.ssh/authorized_keys`.
4. В боте: ➕ Добавить сервер — введите имя, IP/домен, порт и
   пользователя; проверьте SHA256-отпечаток хоста и подтвердите.
5. Настройте sudoers на целевых серверах согласно инструкции,
   чтобы предоставить ровно те команды, которые нужны боту.

## Файлы и структура (после установки)

Пример расположения рабочих файлов на хосте, где запущен бот:

```text
/home/tgbot/tg-bot-env/
- bot.py
- .env               — BOT_TOKEN, ADMIN_IDS
- venv/              — виртуальное окружение Python
- keys/              — приватные ключи/файлы (строго ограниченные права)
- servers.json       — конфигурация серверов
- users.json         — данные пользователей
- known_hosts        — отпечатки хостов
- audit.log          — журнал действий
```

## Безопасность

- Бот запускается от непривилегированного пользователя (`tgbot`) и
  работает в venv.
- Скрипты и доступы на целевых узлах конфигурируются через отдельного
  пользователя (`botadmin`) с ограниченным sudo-доступом.
- Токен бота хранится в `.env` с правами 600 — никогда не
  публикуйте этот файл.
- TOFU (trust-on-first-use) проверка отпечатка хоста при добавлении
  сервера.
